# 축1 — 근로계약·채용·외국인

## 1. 근로계약 명시사항 (근기법 §17, 시행령 §8)

**서면 교부 4항 필수**:
1. 임금 (구성항목·계산방법·지급방법)
2. 소정근로시간
3. 휴일 (§55)
4. 연차유급휴가 (§60)

**시행령 §8 추가 명시 (총 14항)**:
- 취업장소, 종사업무
- 취업규칙 필수기재 (승급·상여·퇴직급여·휴직·재해부조 등)

**단시간·기간제 추가** (기간제법 §17): 근로일·근로일별 근로시간 서면 명시

**위반 시 벌칙**: 근기법 §114 — **500만원 이하 벌금**. 기간제·단시간 위반은 과태료 500만 (기간제법 §24)

## 2. 채용절차법

- **§4의3**: 직무무관 개인정보(용모·키·체중·출신지역·혼인·재산·직계존비속 학력·직업·재산) 요구 금지
- **과태료 500만** (동의 받아도 면제 ✗)
- **§11**: 채용서류 반환 의무

## 3. 수습·시용

- 수습기간 3개월: 본채용 거부는 객관적 합리성·사회통념상 상당성 필요 (대법 2006.2.24. 2002다62432)
- 3개월 이상 근무 시 해고예고 30일 적용
- 평가기준·서면평가 절차 사규 명문화 필수

## 4. 경업금지·전직금지 약정

- **대법 2010.3.11. 2009다82244** 7요소:
  1. 보호할 가치 있는 사용자의 이익
  2. 근로자의 퇴직 전 지위
  3. 경업제한 기간·지역·대상 직종
  4. **대가 제공 유무**
  5. 퇴직 경위
  6. 공공의 이익
  7. 기타 사정
- 대가 없는 광범위 경업금지 = 민법 §103 위반 무효
- 가처분 인용 요건 (대법 2007.3.29. 2006마1303)

## 5. 외국인근로자 (E-9·외국인고용법)

| 비자 | 적용 |
|---|---|
| E-9 (비전문취업) | 고용허가제, 최초 3년 + 재고용 1년 10월, 사업장 한정 |
| E-7 (특정활동) | 전문직 85개 직종, GNI 80% 임금요건 (2025 약 3,200만) |
| D-8 (투자) | 외국인투자기업, 1억+ 투자 |
| F-2/F-5/F-6 | 사업장·직종 제한 없이 취업 자유 |
| H-2/F-4 (동포) | 동포 특례, 단순노무 일부 가능 |

**사업장 변경**:
- 최초 3년 중 3회, 재고용 1년 10월 중 2회
- **사용자 귀책(임금체불·성희롱·폭행·상습폭언) 시 무제한·동의 ✗**

**의무**: 표준근로계약서, 16시간 사전교육 + 입국 후 2일 취업교육, 모국어 안전보건교육 (미실시 500만 과태료)

**보험**: 출국만기보험·귀국비용보험 (사용자 부담)

## 6. 사내하청·파견·노무제공자

### 위장도급 5요소 (대법 2010다106436)

1. 지휘·명령
2. 사업 편입
3. 인사권
4. 전문성·기술성
5. 독립적 조직

→ 5요소 종합 판단

### 노무제공자 (산재법 2023.7.1 개정)

- 전속성 요건 폐지, '특고'와 '플랫폼 종사자' → **'노무제공자'** 재정의
- 산재 의무가입 직종 확대 (퀵·대리·플랫폼·새마을금고 공제모집인·방과후강사 등)

## 7. 5인 미만 사업장 단계 확대 (2025~2028)

| 단계 | 시기 | 적용 |
|---|---|---|
| 1단계 | 2025 하반기~ | 직장 내 괴롭힘, 모성보호 |
| 2단계 | ~2027 | 연차유급휴가, 대체공휴일 |
| 3단계 | 2028~ | 부당해고 제한, 가산수당 |
