# 축3 — 해고·징계·노동위 구제

## 1. 정당한 이유 (근기법 §23①)

"정당한 이유 없이 해고·휴직·정직·전직·감봉·기타 징벌 ✗" — **5인 이상** 적용

## 2. 정리해고 4요건 (§24)

1. **긴박한 경영상 필요성** — 도산 회피 한정 ✗, 장래 위기 대처 + 객관적 합리성 (대법 2010다3629)
2. **해고회피노력** — 희망퇴직·고용유지지원금·계열사 전적·전환배치 사전 거침
3. **합리적·공정한 대상자 선정** — 객관적 기준
4. **근로자대표와 50일 전 협의**

4요건 모두 충족 필요. 입증 부족 시 부당해고 80% 패소.

## 3. 해고예고 (§26)

- 30일 전 예고 또는 30일분 통상임금 (해고예고수당)
- **3개월 미만 근로자 제외**
- 천재사변·근로자 고의로 막대한 지장 등 예외

## 4. 서면통지 (§27)

- 해고사유·해고시기 **서면 통지** 의무
- 위반 시 **해고 자체 무효** (절대적 요건)

## 5. 부당해고 구제신청 (§28)

```
[해고일]
   ↓ 3개월 내 (D+90)
[지방노동위 구제신청]
   ↓ 60일 내 (의무)
[심문회의 + 판정]
   ↓ 30일 내 (판정서 송달)
[판정 결과]
   ├─ 부당해고 인정 → 원직복직 + 해고기간 임금 + 30일 이행
   │                  ↓ 미이행
   │             [이행강제금 500만~3,000만, 매년 2회·최대 2년]
   └─ 사용자 측 패소 시 → 10일 내 중앙노동위 재심
                          ↓ 15일 내
                     [행정법원 취소소송]
                          ↓
                     [고법 → 대법]
```

## 6. 이행강제금 (2025.10.23 개정)

- 구제명령 미이행 시 **500만~3,000만 부과** (하한 신설)
- 매년 2회 한도, 최대 2년 반복부과
- 30일 경과 후 부과 시작

## 7. 노동위원회 통계 (최근)

| 항목 | 수치 |
|---|---|
| 부당해고 본안판단 인정률 (2024) | 26.9% |
| 5년 평균 본안 인정률 | 32.6% |
| 화해 비율 (2023) | 32.3% |
| 부당노동행위 평균 인정률 | 12.3% |
| 각하 1위 사유 (2023~24) | "5인 미만" 49~58% |
| 평균 처리 — 초심 | 48~60일 |
| 평균 처리 — 재심 | 84~90일 |
| 재심판정 유지율 | 84.2% |
| 행정소송 1심 평균 | 401일 |

## 8. 정당 사유 vs 부당해고 (대표 사례)

### 정당
- 정당한 사유 없는 3일 이상 무단결근 (대법 2002.5.28. 2001두10455)
- 횡령·폭행 등 중대 비위
- 정리해고 4요건 모두 충족

### 부당
- 서면통지 누락
- 소명기회 미보장
- 양정 비례원칙 위반 (동종사례 비교)
- 정리해고 4요건 입증 부족

## 9. 권고사직 vs 해고

| 구분 | 권고사직 | 해고 |
|---|---|---|
| 자발성 | 합의 (비자발) | 비자발 |
| 실업급여 | 가능 (코드 23) | 가능 (중대귀책 시 제한) |
| 부당해고 다툼 | 합의해지면 ✗ | ○ |
| 권장 | 평가 객관 증빙 부족 시 | 명백한 비위 |

대법 2003.10.23. 2002다4429 — 진의에 의한 합의해지면 부당해고 ✗, 강요·기망 시 무효

## 10. 시용·수습 본채용 거부

- 대법 2002다62432 — 보통 해고보다 넓게 인정, 객관적 합리성·사회통념상 상당성 필요
- 평가표·면담기록 객관 증빙 필수
- 3개월 이상이면 해고예고 30일

## 11. 대기발령

- 대법 2007.5.31. 2007두1460 — 별도 인사처분, 직권면직 정당사유 필요
- 1년 초과 장기 대기발령 → 직권면직 정당성 검토
- 대기발령 → 당연퇴직 규정 = 실질 해고

## 12. 전직·전보 3요건 (대법 일관)

1. 업무상 필요성 (인사권자 광범위 재량)
2. 생활상 불이익 비교형량 (통상 감수 범위 초과 ✗)
3. 신의칙상 절차 — 근로자 협의

**전적(轉籍)**: 근로자 동의 필수 (전보와 구별)

## 사용자측 부당해고 구제신청 대응 D-Day

### 즉시 (D+0)
- [ ] 인사위원회 회의록·소명자료·평가자료 보존
- [ ] 해고통지서 사본·교부확인서·내용증명 확보
- [ ] 노무사·노동전문 변호사 선임

### D+7 (답변서 작성)
- [ ] 해고사유 객관적 입증자료 시간순 정리
- [ ] 절차적 정당성(소명기회·서면통지) 입증
- [ ] 양정 적정성(동종사례·취업규칙 근거)
- [ ] 권고사직·합의해지 항변 검토

### 심문회의 (D+50~60)
- [ ] 참석자 3명 이내 (인사·직속·대표)
- [ ] 사실관계 시간순 정리, 증거 매핑
- [ ] 위원 질문 대비 Q&A
- [ ] 위원 성향 사전 파악 (공익·근로자·사용자 위원 비율)

### 판정 후
- [ ] 부당해고 시: 30일 내 원직복직 + 임금 지급
- [ ] 이행강제금 회피 (500만~3,000만/회·최대 2년)
- [ ] 재심(10일 내)·행정소송(15일 내) 검토
- [ ] 화해 가능성 적극 고려 (1심까지 가면 1년+)
