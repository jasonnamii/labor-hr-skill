# 축7 — 퇴직·퇴직연금·스톡옵션·사회보험

## 1. 퇴직금·퇴직연금

### 퇴직급여보장법

- 1년 이상 근속, 평균임금 30일분 이상

### 중간정산 제한 사유 (시행령 §3)

1. 무주택자 본인명의 주택 구입
2. 무주택자 전세보증금
3. 본인·배우자·부양가족 6개월+ 요양
4. 5년 내 개인회생·파산
5. 임금피크제·근로시간 단축·천재지변

### 퇴직연금 DB/DC/IRP

| 유형 | 운용 | 부담 |
|---|---|---|
| **DB(확정급여형)** | 회사 운용 | 퇴직금 사전 확정 |
| **DC(확정기여형)** | 근로자 운용 | 회사 연 임금 1/12 이상 적립 |
| **IRP(개인형)** | 개인 | 퇴직 시 자동 이체, 횟수 제한 없이 중도인출 |

### 퇴직소득세 계산

(퇴직금 − 근속연수공제) ÷ 근속연수 × 12 = 환산급여 → 환산급여공제 → 과세표준 → 세율 → ÷ 12 × 근속연수

**근속연수공제 한도**:
- 5년 이하: 100만/년
- 6~10년: 200만/년
- 11~20년: 250만/년
- 20년+: 300만/년

### 임원 퇴직금 한도 (법인세법 시행령 §44)

- 정관 정함 시 정관 한도, 없으면: (퇴직 전 1년 총급여 × 1/10 × 근속연수)
- 한도 초과는 손금불산입 → 근로소득 과세

### 퇴직금 압류금지

- 국세징수법: 퇴직금의 **1/2 한도** 압류제한

### 연금 vs 일시금

- 만 55세+ + 가입 5년+ → 연금 수령, 10년+ 분할 시 절세
- 연금소득세 = 퇴직소득세의 60~70% 수준
- 연금수령 시 분리과세 (연 1,500만 이하): 3.3~5.5% 저율

## 2. 스톡옵션 (상법 §340의2 + 벤처기업법 §16의3 + 조특법 §16의2~4)

### 상법

- 발행주식 10% 한도
- 행사가액 부여 당시 시가 이상
- 부여일로부터 2년 이상 재임·재직

### 벤처기업법 특례

- 발행한도 **50%**
- **시가 이하 발행 허용** (2026.1 직원당 20억 한도 확대)
- 비등기임원·외부전문가 부여 가능

### 조특법 과세특례 (2027.12.31까지)

1. **비과세**: 연 2억 / 누적 **5억** (벤처)
2. **분할납부**: 5년간 1/5씩
3. **양도소득 과세이연**: 행사 시점 근로소득 ✗, 양도 시 양도소득(22%)

### 과세 구분

| 시점 | 구분 |
|---|---|
| 재직 중 행사 | **근로소득** (행사가액 vs 시가 차액) |
| 퇴직 후 행사 | **기타소득** |
| 고용관계 없이 (외부자문) | 기타소득 |

### 벤처 스톡옵션 부여~행사 체크리스트

**부여**
- [ ] 정관 근거 (상법 §340의3)
- [ ] 주주총회 특별결의
- [ ] 부여계약서 — 행사가액·기간·가득·재직요건
- [ ] 부여 시점 벤처기업 확인 필수
- [ ] 부여 후 2년 이상 재직 요건 명시

**재직 중 행사**
- [ ] 행사이익 = (행사 시점 시가 - 행사가액) × 주식수
- [ ] 근로소득세 원천징수
- [ ] 비과세 특례 적용 신청 (연 2억/누적 5억)
- [ ] 분할납부 또는 양도소득과세이연 선택

**퇴직 후 행사**
- [ ] 기타소득세 원천징수 (필요경비 인정 적음, 보통 불리)
- [ ] 비과세·분할납부 특례 적용 가능 여부

## 3. 사회보험 요율 (2026)

| 항목 | 요율 | 부담 |
|---|---|---|
| **국민연금** | 9.0% (인상안 9.5% 진행 중) | 노사 4.5%씩 |
| **건강보험** | **7.19%** (7.09→7.19) | 노사 3.595%씩 |
| **장기요양** | **0.9448%** (건보료의 12.95%) | 노사 분담 |
| **고용보험(실업급여)** | 1.8% | 노사 0.9%씩 |

| 석면피해구제 | 0.06‰ | 20인+ |

### 가입 의무 기준

- **국민·건강**: 1개월 이상 + 월 60시간 이상 (또는 8일+)
- **고용·산재**: 1인 이상 사업장 전면 적용 (예술인·특고·노무제공자 포함)
- **일용**: 월 8일·60시간 미만 = 국민·건강 제외, 산재·고용은 적용

### 두루누리

- 10인 미만 + 월급 270만 미만 신규입사자 — 국민연금·고용보험 80% 지원 (3년)

### 자영업자 산재 의무가입

- 2027년 전국민 산재 목표 (단계 확대 중) [확신 70]

## 4. 청년일자리도약장려금 2026

- **수도권 유형**: 5인+ 우선지원기업, 취업애로청년 정규직 + 6개월 유지 → 1년간 **최대 720만**
- **비수도권 유형**: 1년차 회사 720만 + 2년차 청년 본인 720만 = **합계 1,440만**
- 신청: 2026.1.26~ work24, **채용 전 신청 원칙**

## 5. 청년내일채움공제

- 2024년 신규접수 종료, 사실상 폐지 (기가입자만 유지)

## 6. 실업급여

### 권고사직 vs 해고 vs 자진사직

- 권고사직: 비자발 → 가능 (코드 23)
- 해고: 명백한 비자발 → 가능 (중대귀책 시 제한)
- 자진사직: 원칙 ✗. 단 임금체불 2개월·괴롭힘·통근 3시간+·가족 간병 등 정당사유 시 가능

### 반복수급 감액 (5년 내)

| 횟수 | 감액 |
|---|---|
| 3회 | 10% |
| 4회 | 25% |
| 5회 | 40% |
| 6회+ | 50% |

- 대기기간 7일 → 최대 4주 연장
