# 축4 — 노조·단협·노란봉투법·부당노동행위

## 1. 노란봉투법 (2026.3.10 시행) [확신 90]

### 노조법 §2 ②호 사용자 개념 확대

> "근로계약 체결 당사자가 아니더라도 **근로조건에 대해 실질적이고 구체적으로 지배·결정할 수 있는 지위**에 있는 자도 사용자로 본다"

**구조적 통제** 기준 (고용노동부 해석지침):
- 원청이 하청 근로조건 결정에 대한 의사결정을 제한하는지 (가격·납기·작업방식·인력투입 통제)
- 직접 지휘·명령 불필요
- 파견에 비해 상대적으로 완화된 요건

### 노조법 §2 ⑤호 노동쟁의 대상 확대

추가:
1. 근로조건에 영향을 미치는 사업상의 결정
2. 근로자 지위 결정에 관한 주장의 불일치
3. 사용자의 명백한 단체협약 위반

→ 사업 양도·구조조정·해고 등 쟁의 대상. 이익분쟁 → 권리분쟁까지 확대

### 노조법 §3 손해배상 제한

- 사용자 불법행위에 대한 방어 차원 행위 → 손배책임 면제
- 개별 근로자 책임 산정: 지위·역할·참여 경위/정도·임금 수준·청구 금액 종합. 법원 감경 가능
- **신원보증인 손배책임 면제**

### 첫 사례 (2026.5)

- 현대차 — 2026.5.20 울산지노위 1차 심문회의 → 6.1 2차 회의로 연기

## 2. 단체협약 (노조법 §32)

- 유효기간 최대 **3년** (2021.7 개정 — 2년→3년)
- 서면 + 양 당사자 서명·날인 + 행정관청 신고
- 자동연장 조항 일반화 — 신단협 체결까지 효력

## 3. 단체교섭 절차

```
요구안 제출
   ↓
실무교섭 → 대표교섭
   ↓ 결렬
노동위 조정신청 → 조정전치 10일 (공익 15일)
   ↓
쟁의찬반투표 (조합원 직접·비밀·무기명·과반 찬성)
   ↓
파업
```

## 4. 쟁의행위 정당성 (대법 2001.10.25. 99도4837 전합)

3요건: 목적·절차·수단 모두 정당
- 폭력·파괴 ✗
- 쟁의찬반투표 무효 시 정당성 상실 → 업무방해죄

## 5. 교섭창구단일화 (§29의2)

- 사용자 동의 없이 교섭대표노조 1개로 단일화
- 자율적 단일화 → 과반수노조 → 공동교섭대표단 (10%+ 노조)
- 헌재 2024.6.27 (5:4) 합헌
- **공정대표의무** 위반 시 노동위 시정신청

## 6. 부당노동행위 5유형 (§81)

| 호 | 유형 | 내용 |
|---|---|---|
| 1 | **불이익취급** | 노조 가입·활동 이유 해고·차별 |
| 2 | **반조합(비열)계약** | 비가입·탈퇴 고용조건화 (Yellow-dog) |
| 3 | **단체교섭 거부** | 정당 사유 없는 거부·해태 |
| 4 | **지배·개입, 경비원조** | 노조 조직·운영 개입, 전임자 급여·운영비 원조 (예외: 최소 사무소 제공·후생기금) |
| 5 | **보복적 불이익** | 쟁의·신고·증언 이유 불이익 |

## 7. 타임오프 (근로시간 면제, §24)

### 민간 한도 (조합원 규모별)

| 규모 | 한도 |
|---|---|
| 99인 이하 | **최대 2,000시간** |
| 100~199인 | 약 3,000시간 |
| 200~299인 | 약 4,000시간 |
| 300~999인 | 5,000~10,000시간 |
| 1,000인+ | 추가 배려 |

- 교대제 근무 시 20% 추가
- 복수노조 시 합산 한도 후 비례 배분
- **한도 초과 급여 절대 지급 금지**

| 규모 | 한도 |

| 100~299인 | 1,500h |
| 300~999인 | 2,000h |

### 공무원 타임오프 (2024.10)

|---|---|
| 299인 이하 | 1,000h |

## 8. 공정대표의무 (§29의4)

- 합리적 이유 없는 차별 금지
- 사용자도 공정대표의무 부담 (대법 2018.9.13. 2017두40655)
- 절차적 공정대표의무 — 단협 체결 과정 소수노조 의견청취·정보제공
- 타임오프 미배분·지나치게 적은 배분 = 부당노동행위 + 공정대표의무 위반 (병행)

## 9. 필수공익사업장

철도·도시철도·항공운수·수도·전기·가스·석유정제·병원·혈액공급·한국은행·통신
- 필수유지업무 협정 의무
- 대체근로 50%까지 한정 허용
