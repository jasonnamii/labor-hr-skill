# 축6 — 직장내괴롭힘·차별·모성보호

## 1. 직장내괴롭힘 (근기법 §76의2)

### 3요소

> "직장에서의 **지위 또는 관계 등의 우위**를 이용하여 **업무상 적정범위를 넘어** 다른 근로자에게 **신체적·정신적 고통**을 주거나 **근무환경을 악화**시키는 행위"

- **5인 미만 사업장도 적용** (2025 1단계)

### 사용자 조치의무 (§76의3)

- 신고·인지 → **지체 없이 객관적 조사**
- 조사 중 피해자 보호조치(분리·유급휴가) — 의사 반하면 ✗
- 확인 시 피해자 요청 조치(배치전환·유급휴가), 행위자 징계
- **신고자·피해자 불이익조치 금지** (위반 시 **3년 이하 또는 3,000만 이하**, 반의사불벌 ✗)

### 사업주 직접 가해 시 (2024.7.30~)

- 근기법 §116 ①항: **1,000만 이하 과태료**

### 비밀유지의무

- 조사자·보고자·참여자 모두 위반 시 500만 이하 과태료

## 2. 직장내성희롱 (남녀고용평등법 §14)

- 사용자 조사 의무
- 피해자 보호조치
- 가해자 징계
- **사업주가 직접 성희롱 시 1,000만 이하 과태료** (§39)

## 3. 모성보호 2025~2026 디테일 [확신 90]

### 육아휴직

- **1년 6개월 확대** (2025.2.23~): 부모 각자 3개월 이상 사용 시 각각 6개월씩 추가
- 한부모·중증장애아동 양육자도 1년 6개월
- **사후지급금 폐지** (2025.1.1 시작자 전원 매월 전액)

### 6+6 부모육아휴직제

- 자녀 생후 18개월 이내 부모 둘 다 사용 시 첫 6개월 통상임금 100%
- 월 한도 250→300→350→400→450만 (누진)

### 육아휴직 급여 인상

- 1~3개월차 250만
- 4~6개월차 200만
- 7개월~ 160만

### 육아기 근로시간 단축

- 자녀 **12세 이하·초6 이하** (8세→12세 확대)
- 단축 후 주 15~35시간
- 육아휴직 미사용분의 2배 가산 → **최대 3년**
- 급여 상한 200→220만

### 배우자 출산휴가

- **10일 → 20일** (2025.2.23~)
- 1회 → 3회 분할, 사용기한 90→120일
- 중소 20일 전액 고용보험, 대기업 6~20일 지원

### 난임치료휴가

- 연 6일 (**유급 2일** + 무급 4일)

### 임신기 근로시간 단축 + 태아검진

- §74⑦·§74의2 별개 권리, **동시 청구 가능**

### 가족돌봄휴가

- 연 10일 기본 + 재난·감염병 등 연장 시 20일, 한부모 25일

### 임산부 야간·휴일근로 금지 (§70)

- 임부: 명시적 청구 + 고용노동부장관 인가 시만
- 산부(산후 1년): 동의 + 인가
- 산후 1년 미만 시간외: 1일 2h·1주 6h·1년 150h 한도
- 위반: 2년 이하 또는 2천만 이하

### 임신초기(11주 이내) 유·사산휴가

- 5일 → **10일** (2025.2.23~)

## 4. 차별

### 남녀고평법 §8 — 동일가치노동 동일임금

- 위반: 3년 이하 / 3,000만 이하

### 장애인고용촉진법

- 상시 50인+ 사업주 의무고용률 **3.1%** (2024~)
- 미달 시 부담금

### 기간제·파견 차별시정

- 노동위 차별시정 신청 (기간제법 §9)

## 5. 직장 내 괴롭힘 신고 대응 매뉴얼

### D+0 (신고 접수)
- [ ] 서면 또는 구두 신고 모두 접수, 신고자 보호 약속
- [ ] 조사위원회 구성 (인사·법무·외부 노무사 3인 권장)
- [ ] 신고자·피해자 분리 (피해자 의사 우선·강제 ✗)

### D+3~14 (조사)
- [ ] 피해자 → 신고자(목격자) → 행위자 순 면담
- [ ] 면담기록 서면화·서명
- [ ] 카톡·이메일·CCTV 증거 확보
- [ ] **가해자 진술 구체적 양상을 피해자에게 공유** (2024 대법 판례)

### D+14~30 (판정·조치)
- [ ] 조사위원회 판정서 작성
- [ ] 행위자 인사위원회 회부 (변명기회 보장)
- [ ] **피해자 의견청취 후 조치** (남녀고평법 §14⑤)
- [ ] 조사 비밀유지 (위반 시 형사처벌)

### 상시 (예방)
- [ ] 매년 1회+ 예방교육 (§76의2)
- [ ] 취업규칙 처리 절차 명문화
- [ ] 익명 신고채널 운영
- [ ] 임원·관리자 별도 교육

## 6. 사용자 책임 — 위자료 (2024 대법)

- 회식 폭행·차량 사적 이용·휴가 직전 부당 업무지시·허위 인사평가
- → 직장 내 괴롭힘 + 안전배려의무 위반 → 위자료 책임
